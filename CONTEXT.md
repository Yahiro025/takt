# KEEBY sounds

Terms used when comparing Keeby's recordings with KEEBY's sound profiles.

## Language

**Switch recording**:
A recorded sound of a particular keyboard switch. Two recordings of the same switch are not necessarily the same recording.
_Avoid_: Exact match based only on a switch name

**Sound profile**:
A selectable collection of recordings and their assignments to keys and key actions.
_Avoid_: Switch when referring to a complete profile

**Press sound**:
The recording assigned to a key being pressed down.
_Avoid_: Click when the key action matters

**Release sound**:
The recording assigned to a key being released.
_Avoid_: Press sound for a release action
